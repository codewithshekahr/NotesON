# NotesON

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fcodewithshekahr%2FNotesON)

An all-in-one academic portal for students to access notes, study materials, and resources in one place. This application serves as a unified portal for accessing lecture notes, previous years' question papers, and essential study materials across various semesters and branches.

## Features
- **Semester-wise categorization**: Easy access to notes organized by semester.
- **Subject-wise folders**: Browse notes specifically for each subject.
- **Local PDF viewing**: Native browser support for viewing and downloading notes.
- **Custom Branding**: Fully customized layout with unique branding for Shekhar Kashyap.

## Tech Stack
- **React + Vite**: For a high-performance, modern frontend.
- **Lucide React**: For sleek, consistent iconography.
- **Vercel**: Optimized for seamless edge deployment.

## Deployment
To deploy this project yourself, click the button above and connect your GitHub repository to Vercel. 

**Note**: The 2.4GB `public/all year notes` folder is gitignored. For production use, please host your large assets on cloud storage.
